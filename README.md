# rust-eml
Search through eml space using a rust-based bruteforcer

## Purpose
Make a bruteforcer tool to search through eml space for strings that match a given operator pattern.
- Based on this paper: [https://arxiv.org/html/2603.21852v2](https://arxiv.org/html/2603.21852v2)
